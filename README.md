# Закрывающий тег

Проектная работа о пути в изучении веб-разработки. На странице собраны восемь карточек-рефлексий, CSS-фильтры, адаптивная вёрстка, анимированная SVG-иконка сердца и модальное окно на элементе `dialog`.

https://nickkurdin.github.io/zakrivayuschiy-teg-f/

## Технологии

- семантические HTML5-элементы;
- адаптивная вёрстка с `clamp()` и медиавыражением;
- CSS-переменные, градиенты, фильтры и режимы смешивания;
- CSS-переходы и `@keyframes`;
- вариативный шрифт Inter;
- JavaScript для лайков и открытия диалога.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер в корне проекта.
